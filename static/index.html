OPERATOR GUIDE

From a weak signal
to a recovery decision.

Pause the simulation while explaining a frame. Use Step +2s for one causal tick, or 4× playback to show recovery without waiting. These controls affect all viewers.

  1. Run a scenario. A seeded fault degrades one dependency. Every scenario resets this shared sandbox.
  2. Follow the evidence. Robust anomaly scores compare recent latency and errors to a rolling baseline. Dependency propagation flags exposed callers.
  3. Inspect the origin. Root cause ranking favors anomalies not explained by failing dependencies. Evidence strength is a heuristic, not a calibrated probability.
  4. Compare and recover. Five copies of the simulator run for 40 simulated seconds with identical random streams. Apply an action, then watch observed health recover.

Telemetry, fault injection, and remediation are synthetic. Recovery trials can inspect simulated fault state; this is a digital-twin prototype, not a production integration. A circuit breaker isolates the source temporarily and may sacrifice functionality.

All visitors share this sandbox. Resetting or running a scenario affects every viewer. Export captures the currently buffered telemetry, analysis, forecast trajectories, observed prediction lead times, and action history.
